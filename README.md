# 🎨 Artistic Painting Effect Generator
A Python-based image processing project that transforms ordinary images into painting-style artwork using OpenCV.

## Features
- Histogram Equalization
- Bilateral Filtering
- Canny Edge Detection
- Morphological Dilation
- Painting Effect Generation

## Technologies Used
- Python
- OpenCV
- NumPy

## Project Structure
Artistic-Painting-Effect-Generator
- painting_effect.py
- images/
- output/
- README.md
- requirements.txt

## Installation
bash
pip install -r requirements.txt

## Run
bash
python painting_effect.py

## Output
The program displays:
- Original Image
- Painting Effect
It also saves the generated image inside the **output** folder.

## Concepts Used
- Grayscale Conversion
- Histogram Equalization
- Bilateral Filtering
- Canny Edge Detection
- Morphological Operations
